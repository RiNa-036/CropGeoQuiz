# Crop Geo Quiz

## Features Used

* **Interactive Crop Geography Quiz:** Users can participate in a quiz based on different crops and their geographical regions.
* **Multiple-Choice Questions:** Users can select the correct answer from multiple options.
* **Dynamic Question Management:** Quiz questions and options are retrieved and managed dynamically from the database.
* **Answer Validation:** The system checks the selected answer and determines whether it is correct or incorrect.
* **Score Calculation:** The system calculates and displays the user's score based on the answers.
* **User-Friendly Interface:** A simple web interface is provided for easy interaction with the quiz.
* **Database Integration:** Crop, geography, question, and answer-related information is stored and managed using MySQL.
* **Java-Based Backend:** Java is used to implement the application logic and handle communication between the web interface and database.

## Tools and Technologies Used

* **Java:** Used for implementing the core application logic and backend functionality.
* **Servlet:** Used to handle HTTP requests, process user interactions, and connect the web interface with the backend.
* **JSP (JavaServer Pages):** Used to create the dynamic web pages and display quiz questions, options, and results.
* **JDBC (Java Database Connectivity):** Used to establish a connection between the Java application and the MySQL database and perform database operations.
* **MySQL:** Used as the relational database for storing crop information, geographical data, quiz questions, answers, and related records.
* **HTML & CSS:** Used to structure and design the web pages and create the user interface.
* **Apache Tomcat:** Used as the web server/application server for running the Java Servlet and JSP-based web application.
* **IntelliJ IDEA:** Used as the development environment for building and testing the project.
* **Git & GitHub:** Used for version control, source code management, and project hosting.

## Significance of the Project

**Crop Geo Quiz** is an educational web application that combines **geographical knowledge, agriculture, and interactive learning**. The project helps users learn about different crops and their geographical distribution through an interactive quiz system.

The project demonstrates practical knowledge of **Java Web Development**, including **Servlet, JSP, JDBC, and MySQL database integration**. It shows how a Java-based web application can communicate with a relational database to store, retrieve, and process dynamic information.

The project also provides practical experience in **CRUD/database operations, request handling, dynamic web page generation, user interaction, and backend development**. By combining agricultural and geographical information with a quiz-based system, the project makes learning more engaging and interactive.

Overall, Crop Geo Quiz is significant as it demonstrates the development of a **complete database-driven Java web application** while applying programming, database management, and problem-solving skills to an educational purpose.
